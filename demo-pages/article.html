On-Device Visual Perception for Light-weight Browser Agents

Autonomous web agents have historically relied on streaming raw viewport screenshots to massive cloud vision-language models. While effective in unconstrained benchmarks, this approach suffers from significant privacy leakage, prohibitive latency, and unpredictable token consumption.

Key Finding: Local visual perception combined with DOM accessibility semantics delivers deterministic grounding in sub-100ms cycles without transmitting a single unredacted pixel or user credential.

1. The Privacy Boundary Invariant

In our architecture, the client extension enforces an uncompromised privacy boundary. All sensitive data—including password fields, email addresses, phone numbers, and OCR-detected tokens—are identified on-device. Before any payload leaves the browser context, raw coordinates and values are masked in-memory.

Furthermore, form filling values entered by the user or specified in natural language tasks remain strictly local in popup memory. The remote reasoning gateway receives only structural questions and sanitized field labels.

2. Multimodal Fusion and Grounding

Rather than relying on fragile single-modality heuristics, the agent fusions three independent streams:

First, the DOM accessibility tree provides semantic tags such as role="button", aria-label, and question containers. Second, an on-device ONNX vision model classifies high-level visual scenes. Third, a local OCR pipeline verifies non-DOM text elements.

3. The Human-in-the-Loop Safety Gate

Autonomous execution is safe for navigation and form field entry. However, consequential actions—such as clicking Submit, Confirm, Transfer, or Purchase—pose irreversible side effects.

Our local safety gate halts the agent loop whenever a high-impact action is proposed. A non-dismissible human approval modal presents the exact action, target, and risk justification. Only upon explicit human consent is the action dispatched.
